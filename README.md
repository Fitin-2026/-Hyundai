# 옆자리

출발하면 옆자리가 조용히 함께해요 — 운전자의 주행 요약을 위치 정보 없이 가족에게 전하는 차량용·모바일 앱

## 실행 방법
1. Android Studio에서 이 저장소를 열고 Gradle Sync를 완료합니다.
2. 실행 구성에서 `automotive`를 선택하고 Pleos Connect 에뮬레이터에서 실행합니다.
3. 모바일 앱은 `mobile`을 선택해 일반 Android 에뮬레이터 또는 기기에서 실행합니다.
4. APK로 바로 설치하려면 `apk/` 폴더의 APK를 사용하세요.

## 테스트 환경 및 필요한 설정
- Android Studio: Android Studio Rabbit 2 | 2026.2.2 (Build #AI-262.10968.63.2622.16730706)
  - 개발 OS: Windows 11
- JDK 11 이상, minSdk 29, compileSdk/targetSdk 37
- 외부 서버·API 키가 필요 없습니다. 안부 공유는 앱 내 메모리 방식으로 동작하는 데모입니다.

## 개발 환경 (Pleos Connect 에뮬레이터)
- 에뮬레이터 버전: Pleos Connect v2.1.0 (Android 14.0, API 34, Google APIs, x86_64)
- 화면 규격: 2560 x 1440 px, 12.8인치, 160 dpi

## APK 위치
- `apk/핏인_옆자리_release.apk`

## 구조
- `automotive` 차량용 앱
- `mobile` 모바일 앱
- `shared` 공통 로직
  
## 서비스 확장 계획 (기획 단계)
옆자리는 출발 후 도착까지의 안심 정보를 위치 노출 없이 가족에게 전달하는 서비스입니다. 이 구조를 돌봄·통학 이동 서비스로 확장합니다.
1단계는 운전자와 가족(현재 개발 버전)입니다. 2단계는 요양원·데이케어센터·병원 송영 차량으로, 보호자가 어르신의 안전한 도착을 알림으로 확인합니다. 3단계는 어린이집·학원·태권도장 통학 차량으로, 하차 확인 결과를 보호자에게 전달하고 시설 운영자에게는 승하차 기록을 남겨 법적 의무 이행 근거로 활용하게 합니다.
기존 서비스가 실시간 위치 공유 중심인 것과 달리, 옆자리는 도착·안전 여부만 전달해 개인정보 수집을 최소화합니다.
